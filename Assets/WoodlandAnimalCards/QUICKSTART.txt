WOODLAND ANIMAL CARDS — UNITY KIT

1. Keep this folder at Assets/WoodlandAnimalCards.
2. Use Unity 6 + Unity UI/TMP. Import TMP Essential Resources if prompted.
3. Run Tools > Woodland Animal Cards > Generate Both Styles.
4. Drag ONE generated prefab into your scene. TallLeft stays on the left;
   Wide is centered. Both styles support all seven supplied species names.
5. Use your existing EventSystem with Input System UI Input Module.
6. Add your animal Sprite to the matching generated AnimalCardData asset.
7. Play: questions show sample answers, Close hides the card.
8. Talk is a microphone UnityEvent hook only. It does not record audio.

Full beginner instructions are in START HERE.txt at the root of the download.
Integration details and the editor test checklist are in Documentation/.
No prebuilt prefabs are included; the menu generates 28 in a new output folder.
No Unity Editor compile, Play Mode test or player build was run for this portable kit.
